# tedx-bphc-2026

Public website for TEDx BPHC 2026, built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

## Structure

- `src/app/` — routes: `/` (home), `/speakers`, `/team`, `/sponsors`, `/gallery`, `/schedule`, `/venue`, `/faq`
- `src/components/layout/` — Navbar, Footer
- `src/data/` — content types and (eventually) content data
